# Smart Caspian Transit — MVP для хакатона

## Что реализовано
- Панель управления и список грузов.
- Цифровой двойник: статус, маршрут, параметры груза.
- Предиктивная оценка риска задержки (эвристическая модель 0–100).
- Симулятор погоды, загруженности порта и задержки железной дороги.
- Pre-clearance: демонстрация предварительного одобрения документов.
- Журнал аудита с SHA-256-хешами, связанный с предыдущей записью.
- Альтернативный сценарий маршрута.
- Расчёт ориентировочного CO₂ по весу, расстоянию и типу транспорта.

## Запуск
Требуется Python 3.9+.

### macOS / Linux
```bash
cd smart_caspian_transit
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

### Windows
```bat
cd smart_caspian_transit
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

## Показать сайт на других ноутбуках в одной Wi-Fi сети
Запускайте `python app.py` на главном ноутбуке. Узнайте его локальный IP:
- macOS: System Settings → Wi-Fi → Details → IP address
- Windows: `ipconfig`

На других устройствах откройте `http://IP-АДРЕС:5000`.
Если не открывается, разрешите Python входящие подключения в firewall и убедитесь, что все устройства в одной сети.

## Важно для защиты
Это демонстрационный прототип с условными данными. Он не подключён к реальным портам, метеосервисам или таможенным API. Хеш-журнал показывает принцип контроля целостности, но не является распределённым блокчейном. Коэффициенты CO₂ и модель риска учебные. Для промышленного внедрения потребуются исторические данные, обучение и валидация ML-модели, реальные API и юридически значимый электронный документооборот.
